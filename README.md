# Java LifePilot 

**Your Personal Java Assistant** — a beginner-friendly console application built to practice core Java fundamentals.

## Description

Java LifePilot is an interactive menu-driven program written in plain Java. The code is intentionally simple, well commented, and organized into one method per feature.

## Features

1. **Quick Addition** — add two integers
2. **Smart Calculator** — +, -, *, /, % with division-by-zero handling
3. **Number Analyzer** — sign, even/odd, and prime status
4. **Compare Numbers** — find the largest of two or three numbers
5. **Leap Year Detector** — uses the correct leap year rule
6. **Prime Number Checker** — loop-based divisibility check
7. **About Project** — project information
8. **Exit** — friendly goodbye

## Java Concepts Practiced

- Variables and primitive data types
- Arithmetic, relational, and logical operators
- Input/output with Scanner
- if / else if / else
- switch statements
- for and while loops
- Methods and return values
- Boolean expressions
- Basic problem solving
